Field measurements

Values and source labels are user-reported. Entry bounds prevent malformed records; they are not agronomic thresholds. Blank is unknown; zero is a measured zero.

Reviewed measurement CSV import

Use the template. Values must use the listed units and timestamps must include an explicit timezone. Upload previews are not measurements. Review all rows before confirming; invalid rows prevent import. Test imports remain test material.

Manual case questions

Record questions and human answers for this field. Only you choose whether an answer is adequate. Closing case tracking does not verify a diagnosis, complete work or clear workspace tasks.

Explicit evidence links

Select the observation this source supports. Preview the exact source before linking it. A hash checks stored consistency, not authenticity or agricultural accuracy. Test measurements and test images cannot be linked as farm evidence.

Compare frozen review bundles

Choose two captures for the same observation. Differences describe saved JSON sections, not field changes or treatment effectiveness. Earlier captures are not edited.

Recorded cash activity

Net cash is recorded sales minus recorded expenses. It is not profit. This view does not create financial entries, estimates or payment instructions.
