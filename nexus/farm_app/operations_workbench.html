Daily workflow

  1. Read the saved records and review dates.
  2. Plan work manually with a named owner and constraints.
  3. Record what was actually done, with unresolved issues.
  4. Capture a review bundle when ready to review evidence.

System checks
Checks SQLite integrity, record relationships, captured payload hashes, photo bytes and work-order hash chains. Results do not verify agricultural accuracy or identities.
Backup and recovery
Run these commands in the NEXUS project folder:
python -m nexus.farm_app.operations_recovery backup
python -m nexus.farm_app.operations_recovery verify --database "backups/YOUR-BACKUP.sqlite3"
python -m nexus.farm_app.operations_recovery restore --source "backups/YOUR-BACKUP.sqlite3" --destination "nexus-recovered.sqlite3"
Restore previews by default. Add --commit to create a new verified database file. Existing files are never overwritten. External files are not included in SQLite backups.
