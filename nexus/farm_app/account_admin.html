Help — accounts, roles and recovery

Only an enabled platform administrator can use this page. Farm ownership alone grants no platform administration. Creating an account does not assign it to a farm. Search by username and select an account ID below. No password hashes, session secrets or recovery tokens are shown.

Owner: authorised farm reads and pilot notes, plus last-owner protection. Editor: the same current pilot record operations without owner status. Viewer: read only. Manager, worker and adviser permissions are not implemented; do not assign qualifications through these technical roles.

To change a membership, select the account, existing farm and role, then Assign role. Remove assignment revokes access on subsequent requests. Assign another enabled owner before removing, demoting or disabling a farm's last enabled owner. Disabling an account signs it out; re-enabling does not restore its old sessions. The last platform administrator cannot be disabled.

Passwords require 12–1024 characters. Fictional username example: example-viewer. Do not reuse example credentials or enter personal data unnecessarily. Use the CLI for operator-assisted recovery: verify identity independently, issue a 15-minute credential into a private file, deliver it privately, then delete the file. The user redeems it on the sign-in page. Credentials are not displayed in this dashboard.

Only the latest 100 activity entries are shown. These record application actions and local operator actions; a database operator can still replace the database. Activity history does not independently authenticate a person's identity. No email or SMS delivery is configured. Keep this pilot local; the full Operations workspace still lacks account enforcement.
